Chat block test page

Static test content for the chat block. Serve it with:

npx -y @adobe/aem-cli up --no-open --forward-browser-logs --html-folder drafts

then open http://localhost:3000/drafts/chat — the dev server mounts the folder under /drafts.

The block needs a gateway URL to work. Either uncomment <meta name="claude-gateway"> in head.html and point it at http://localhost:8787 with the Worker running locally, or expect the block to render in its "not configured yet" state.
